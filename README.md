# hifz-legal

Legal pages for the **Hifz** app (Qur'an memorization, Hermes Digital), published with GitHub Pages at
https://hermesdigitalbr-spec.github.io/hifz-legal/

- `/terms`, `/privacy`, `/support`. The app links to `terms.html` and `privacy.html` — do not rename.
- To edit: change the text in `build.py` and run `python3 build.py`.
- `support@hermes.com.br` is the intended support address (do not change).
